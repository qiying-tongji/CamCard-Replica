# 扫描测试记录

截图来自正在运行的 CardVault，设备是 iPhone 17 Pro 模拟器（iOS 26.0）。每一张都是手机画面，带状态栏、导航栏和底部标签。大文件夹里 40 个小文件夹，对应 C001 到 C040。

每个小文件夹里有 5 张图：

| 文件 | 画面 |
| --- | --- |
| 01_自动识别边界.png | 导入名片。蓝框是自动检出的四角，还没拖过 |
| 02_OCR结果.png | 核对名片信息。识别刚填进表单，还没改字 |
| 03_手动更改后.png | 同一张核对表。对照原稿改完之后 |
| 04_名片详情.png | 保存后打开的这张名片 |
| 05_导出结果.png | 点导出后的系统分享页，文件是 vCard |
| 06_导出的联系人.png | 系统打开这张 vCard 后的联系人页，可保存到通讯录 |

自动框如果把字切掉了，会在拍下 01 之后、进入识别之前，把四角拉到接近整张照片。所以 01 仍是自动框，02 已经是拉框之后的识别结果。拉框这件事写在下面的「四角」一列，核对页上再改的字写在「核对页」一列。02 和 03 看起来一样，就是核对页没有改字。

电话、邮箱、网址只在数字或地址本身不同时才改。多出来的空格、`http://` 不算改动。
