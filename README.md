# CamCard-Replica

同济大学移动应用开发课程作业：用规格驱动开发（SDD），在 6 周内对「名片全能王（CamCard）」做限定功能切片的黑盒复刻。

作业全文在 `移动应用开发课程作业-v2 (1).docx`。英文名称是 *AI-Native Mobile Application Engineering: 100% Black-Box Replication of a CamCard Feature Slice Using SDD + TRAE*。

复刻对象只有一条可以测完的闭环：**名片数字化与联系人管理**。流程是：

进入名片夹 → 拍摄或导入 → 区域检测与校正 → OCR → 字段结构化 → 人工核对与修改 → 保存 → 列表 → 搜索 / 标签 / 详情 → 重新打开 → 导出联系人。

只把一张照片识别成一段文字，不算完成。课程要求的工程顺序是：观察行为 → 规格 → 架构与实现 → 测试 → 差异分析 → 修订 → 回归。AI 生成的代码必须经过测试和人工核对后才能当作结果。

这里的「100%」指的是：在锁定的参考版本、设备、语言和测试集范围内，可观察行为与参考 App 等价。不获取 CamCard 源码，不反编译，不复制其 OCR 模型、服务器或受版权保护的资源。

## 两类验收

确定性功能包括界面、导航、保存、编辑、删除、搜索、标签和导出，按 Reference Test Suite（T01–T20）验收。

概率性功能包括 OCR 以及姓名、公司、职位、电话、邮箱、地址的抽取。评价用固定测试名片和 Ground Truth：保留 OCR 原文和解析结果，算字段准确率，并和参考 App 对照。识别错了必须能人工改正。名片上没有的信息不得补全；没有网址时，网址必须保持为空。

## CardVault

工程按 iOS 17、仅 iPhone 竖屏配置。Bundle ID 是 `edu.tongji.CardVault`，显示名是 CardVault。本地库存 `BusinessCard`、`Tag`、`OCRResult`。原图和校正图用外部存储。相机用途说明是「需要使用相机拍摄名片，以便识别联系人信息。」通讯录用途说明是「需要把选中的名片保存到通讯录。」相册导入使用系统照片选择器。

底部有两个标签：名片夹、扫描。

扫描页可以拍照，或从相册导入。模拟器没有摄像头时，取景使用示例名片。导入后自动检测四边形，可以拖动四角再校正，然后做 OCR。核对页展示姓名、公司、职位、手机、电话、邮箱、网址和地址。空字段保持空，不补全。确认后写入本地数据库，名片夹列表更新。OCR 原文保存在 `OCRResult` 里。

名片夹支持搜索（姓名、公司、职位、电话、邮箱）、标签筛选、备注、编辑、删除、排序和批量操作。详情可以看原图和字段，空字段显示「未填写」，电话、邮箱和网址走系统组件。导出是 vCard 3.0：有值的字段写入文件，空字段不出现；系统打开该文件后可以保存到通讯录。杀进程再打开，原图、改过的字段、标签和备注仍在。

空列表显示「还没有名片」和「扫描第一张名片」，不放入示例名片。

### 和规格文档的对应关系

`02_spec.md` 按 Android 截图规定文案和流程，包括「未确认」队列、分组、8 个校正点，以及分享成纯文本。CardVault 覆盖作业要求的端到端闭环，数据管理用标签而不是分组，导出用 vCard 而不是参考 App 的分享文本。没有实现五个底部标签、未确认队列、传真和多行电话、会员和云同步，也不实现官网回收站。

`03_business_card_schema.md` 按参考 App 的核对页保留了多组电话、邮箱、公司和拆开的地址。CardVault 的 `BusinessCard` 使用单一的姓名、公司、职位、手机、电话、邮箱、网址、地址、备注和标签。

## 运行

需要 Mac 和 Xcode。Windows 上不能编译这个工程。

1. 打开 `CardVault/CardVault.xcodeproj`。
2. Scheme 选择 `CardVault`。
3. 选一台 iPhone 模拟器，运行。
4. 单元测试目标是 `CardVaultTests`。

## 测试记录

`TEST_REPORT.md` 记录的是 2026-10-20、iPhone 17 Pro 模拟器（iOS 26.0）上的一次检查。

单元测试 3 项，通过 2 项，失败 1 项：

- `VisionOCRServiceTests` 通过：C001 能识别出姓名。
- `VCFExporterTests` 通过：有值的字段写入 vCard，空字段不出现。
- `BusinessCardFieldParserTests` 失败：10 张样例、80 个字段里 79 个与正确答案一致。C013 的公司被 OCR 读成「津波咨询」，正确答案是「津渡咨询」。解析器按识别原文保存，核对页可以手改。没有网址的样例，解析结果的网址为空。

同一份报告里，空列表、导入后保存、详情、编辑、删除、重启后数据仍在、搜索、标签和缺网址不补全，是按代码路径核对的。
