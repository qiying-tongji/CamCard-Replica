# CamCard-Replica

同济大学移动应用开发课程：名片全能王（CamCard）功能切片黑盒复刻项目。

## 第一周交付物

- `01_reference_observation.md` — 参考 App（Android 7.90.5.20261016）观察记录
- `02_spec.md` — 功能规格
- `03_business_card_schema.md` — 名片数据结构
- `04_test_plan.md` — Reference Test Plan（T01–T20，不含 T09）
- `05_test_cards.xlsx` — 测试名片 Ground Truth
- `reference_screenshots/` — 参考 App 截图
- `test_card_images/` — 虚构测试名片图片（C001–C040）
- `generate_test_cards.py` — 生成测试名片与 Excel 的脚本

## 说明

测试名片为课程用虚构数据，若教师发放官方测试集请优先使用官方数据。实现阶段使用 SwiftUI，尚未包含 App 源码（第二周起）。
